# My Own Timer

基于 Electron Forge、Vite 和 TypeScript 的 macOS 贴边番茄钟。

## 开发运行

```sh
npm install
npm start
```

已有依赖时直接运行 `npm start`。启动后在屏幕右边显示小胶囊，菜单栏显示计时器图标；不显示 Dock 图标。

## 操作

- 鼠标移入胶囊展开，移出 450ms 后收起；胶囊显示向上取整的剩余分钟。
- 点击开始／暂停；左侧重置按钮重置当前阶段。
- 专注、短休息、长休息默认 25／5／15 分钟；齿轮中可以调整为 1–180 分钟。保存设置会停止并重置当前阶段。
- 每完成 4 次专注准备一次长休息。阶段完成后发声、尝试发送系统通知，并等待手动启动下一阶段。
- 右上角菱形按钮固定展开；设置打开时临时固定。
- 拖动底部手柄，或按住 Option 拖动卡片，在当前边缘调整高度；拖到另一块屏幕后停靠该屏幕的同一边。底部按钮切换左右停靠。
- 菜单栏可显示面板、开始／暂停、切换停靠边缘、退出。

## 计时与持久化

计时在主进程使用结束时间计算，不依赖渲染帧数。睡眠、退出应用期间时间继续流逝；恢复后若阶段已结束，只结算一次，并等待手动启动下一阶段。完成次数是累计次数。

设置、计时和停靠位置保存在 Electron `userData` 下的 `timer-state.json`。程序使用临时文件再重命名保存；无效状态回退默认值。显示器拔出时回到主屏。

## 窗口实现

固定 320×400 DIP 的透明 panel 窗口，内部卡片通过 CSS 展开；主进程以 40ms 间隔检测鼠标位置和可见形状，透明区域启用鼠标穿透。计时快照每 250ms 更新。屏幕横向定位使用完整 bounds，纵向使用 workArea 避开菜单栏和 Dock。

当前实现左右停靠；没有顶部硬件刘海融合。全屏、Stage Manager、自动隐藏 Dock 等行为需在目标 macOS 环境实测。系统通知是否出现取决于系统授权及免打扰设置。

## 检查与打包

```sh
npm test
npm run typecheck
npm run lint
npm run package
npm run make
```

测试使用 Node 22.6+ 的 TypeScript 类型擦除功能。`package` 生成本机应用，`make` 在 macOS 上生成 ZIP；默认未配置发布签名和公证。
